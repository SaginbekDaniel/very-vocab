# Very Vocab

Flashcards + quiz in a single static `index.html` (RU/EN UI, works on mobile). Pick a word set from the title:

- **Very → Stronger** — replace “very + adjective” with one stronger word (50 pairs).
- **B1 Preliminary · C** — Cambridge B1 Preliminary vocabulary list, pp. 8–10 (“by …” – “cyclist”), English → Russian, with parts of speech and the list’s example sentences.

Progress (“Got it”) is stored per word set in `localStorage`.

To add words, extend the `B1` block in `index.html`: one line per entry, `word|part of speech|Russian|examples`.
